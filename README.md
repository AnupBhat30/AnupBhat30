
I build things that start with a question I can’t leave alone.

Mostly product, software and AI systems, but sometimes things that have very little to do with either.

I keep coming back to questions where different fields overlap. Why nature solves problems we keep trying to solve with brute force. Whether we can build machines that understand us without making us worse at thinking.

I like problems where the obvious solution feels slightly wrong.

So I follow the question, learn whatever I need along the way, and build until I understand it a little better.
